Run the application locally

To try the database version, use Python 3.12 and run the commands below from the extracted enhanced folder. They create a Python environment, install the required packages, and load the synthetic records into SQLite. The README has the full setup instructions.

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage_db.py init
.\.venv\Scripts\python.exe manage_db.py import data/demo_animals.json
$env:SHELTER_MODE = "sqlite"
.\.venv\Scripts\python.exe run.py

Then open http://127.0.0.1:8050 in your browser. Keep SHELTER_MODE set to sqlite to try the database features. Without that setting, the application uses the JSON demonstration data.
